# Funriosity

Projeto de construção de um sistema computacional completo a partir de primeiros princípios, abrangendo desde a lógica digital clássica até uma arquitetura de computação quântica.

O objetivo final é um dispositivo de geração dimensional: uma máquina capaz de instanciar uma dimensão física real a partir de um conjunto de parâmetros e preferências definidos pelo usuário. O conceito não
se confunde com realidade virtual, pois não há simulação sensorial, e sim a criação de um domínio físico próprio, governado pelos parâmetros escolhidos.

Para preservar a autonomia do usuário, o sistema é concebido como unidade individual. Cada pessoa operará sua própria máquina quântica, sem dependência de infraestrutura centralizada e, portanto, sem
controle por empresas ou governos.

Objetivos
- [ ] Implementação de portas lógicas
- [ ]Implementação de circuitos aritméticos
- [ ]Projeto e implementação de unidade de processamento
- [ ]Integração em computador completo
- [ ]Desenvolvimento de sistema operacional
- [ ]Descrição do processador em hardware e validação em FPGA
- [ ]Implementação de computador quântico
- [ ]Utilização de energia quântica como fonte de funcionamento
- [ ]Geração de dimensão a partir de parâmetros definidos pelo usuário
- [ ]Construção da máquina quântica individual

Nota final

Projeto de longo prazo. Os objetivos não seguem ordem fixa e podem ser executados em paralelo, conforme a evolução de cada componente.
